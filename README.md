# 🪄 마법사 체스

아이와 함께 즐기는 체스 게임이에요. 판 위의 말들은 **살아 움직이는 돌 조각상**이라서, 상대 말을 잡으면 **⚔️ 결투 장면**이 펼쳐지고 잡힌 말은 와장창 부서져요.

## 주요 기능

- **📖 튜토리얼 (15단계)**: 말마다 ⭐ 별 모으기 미션이 있고, 잡기, 체크, 체크메이트, 캐슬링, 프로모션, 앙파상을 직접 두면서 배워요.
- **👣 이동 가능한 칸 표시**: 말을 누르면 갈 수 있는 칸에 초록 점이, 잡을 수 있는 말에 빨간 테두리가 나타나요.
- **⚔️ 결투 연출**: 말 종류마다 공격 방식이 달라요 (나이트는 말발굽 차기, 퀸은 번개 마법 …). 화면을 누르면 건너뛸 수 있어요.
- **👨‍👧 둘이서 두기**: 한 화면에서 번갈아 두기.
- **🤖 마법 컴퓨터와 두기**: 🐣 쉬움 / 🦉 보통 / 🐉 어려움, 하얀 팀이나 검은 팀 중 골라서 두기.
- **💡 힌트** (한 판에 5번까지), **↩️ 무르기**, **📜 기록장**(두어진 수를 한국어로 기록), 체크 경고.
- 체스 규칙 전부 지원: 캐슬링, 앙파상, 프로모션, 체크메이트, 스테일메이트, 기물 부족·50수·3회 반복 무승부.
- 효과음은 Web Audio로 직접 만들어서 외부 파일이 필요 없어요. 설정(이동 칸, 결투, 소리)은 브라우저에 저장돼요.
- 휴대폰, 태블릿, PC 화면 모두 지원.

## 실행 방법

빌드가 필요 없는 순수 HTML/CSS/JavaScript예요.

```bash
# 방법 1: index.html 파일을 브라우저로 바로 열기
# 방법 2: 로컬 서버로 열기
npm start            # 또는 python3 -m http.server 8000
# → http://localhost:8000
```

## 테스트

```bash
npm test
```

규칙 엔진은 표준 perft 수치(시작 위치, Kiwipete 등)로 검증하고, AI가 한 수 메이트를 찾는지, 튜토리얼 배치가 올바른지도 확인해요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 (메뉴, 보드, 패널, 결투·프로모션·결과 창) |
| `css/style.css` | 마법 테마 스타일과 애니메이션 |
| `js/engine.js` | 체스 규칙 엔진 (합법 수 생성, 체크·메이트 판정, FEN) |
| `js/ai.js` | 마법 컴퓨터 (알파-베타 탐색, 난이도 3단계) |
| `js/duel.js` | 결투 장면 연출 |
| `js/sound.js` | 효과음 합성 |
| `js/tutorial-lessons.js` | 튜토리얼 단계 정의 |
| `js/app.js` | 화면 그리기, 게임·튜토리얼 진행 |
